# 商品価格比較 MVP 要件・実質価格仕様

## 1. 目的と対象範囲

依頼時点の Amazon、楽天市場、Yahoo!ショッピングの商品情報を同じ条件で比較し、ユーザーが支払額とポイントを考慮した実質価格を区別して判断できるようにする。

MVP では新品の通常購入（単品、一括払い）だけを対象とする。中古品、定期購入、セット販売、数量条件付き価格、会員限定価格、ふるさと納税、法人価格は比較対象外とし、候補として取得できても「比較対象外」と表示する。

## 2. 商品の同一性判定

### 2.1 判定に使う項目

| 優先度 | 項目 | 判定ルール |
| --- | --- | --- |
| 1 | JAN/GTIN | 正規化したコードが一致すること。チェックデジットを検証できない値は使用しない |
| 2 | メーカー型番 | メーカー名を正規化したうえで、空白・ハイフン・英字大小を除いて完全一致すること |
| 3 | バリエーション | 容量・内容量、個数、色、サイズ、対応機種、エディションがすべて一致すること |
| 補助 | 商品名・画像 | 候補抽出と目視確認にのみ使用し、単独では同一商品と確定しない |

同一性は次の順で決定する。

1. **自動一致**: 有効な JAN/GTIN が一致し、取得できたバリエーション項目に矛盾がない。
2. **条件付き一致**: JAN/GTIN を取得できず、メーカー型番と全必須バリエーションが一致する。
3. **要確認**: 商品名は類似するが、JAN/GTIN、型番、または必須バリエーションの一部が未取得である。
4. **不一致**: 識別項目が異なる、または単品とセット品、新品と中古品など販売単位・状態が異なる。

「要確認」は価格一覧に候補として分離表示し、最安値の決定には含めない。出品者独自の商品管理番号（ASIN、店舗 SKU など）は同一サイト内の再取得には利用できるが、サイト横断の同一性根拠にはしない。

### 2.2 正規化

- JAN/GTIN: 数字以外を除去し、桁数とチェックデジットを検証する。
- メーカー名・型番: Unicode を正規化し、前後空白を除去する。型番比較では空白、`-`、`_`、英字の大小を無視する。
- 容量・サイズ: 単位を換算可能な共通単位へ統一する（例: `1 L = 1000 ml`）。
- 色: メーカー公式の色名または色コードを優先する。「ブラック」と「黒」のような別名辞書による一致は、根拠を画面に表示する。
- 個数: `500 ml × 2本` と `1 L × 1本` は総量が同じでも別商品とする。

## 3. 取得・表示項目

比較カードには以下を表示する。金額はすべて円単位とし、内訳と総額を混同させない。

| 項目 | 表示・保持ルール |
| --- | --- |
| サイト・販売者 | モール名、店舗名または販売元 |
| 商品 | 商品名、画像、JAN/GTIN、メーカー型番、容量・個数・色・サイズ等 |
| 本体価格 | 表示価格と税込/税別区分。税別の場合は取得できた税率で税込換算した値も表示 |
| 送料 | 金額、無料、条件付き無料、未確認を区別 |
| セール | 適用後価格、通常価格、名称、終了日時（取得できた場合） |
| クーポン | 値引額または率、最低購入額、対象者、取得・入力の要否、期限、適用可否 |
| ポイント | 獲得見込み、還元率、内訳、上限、用途・期限、付与条件、現金相当としての算入可否 |
| 支払額 | 税込の商品価格から適用確定済み値引きを引き、送料を加えた金額 |
| 実質価格 | 支払額から算入可能ポイントを引いた参考値 |
| 取得情報 | 取得日時（ISO 8601、タイムゾーン付き）、商品 URL |
| 判定 | 同一性（自動一致、条件付き一致、要確認、不一致）と根拠 |

一覧の主表示は **支払額** と **実質価格** の両方とし、「実質価格」は参考値であって決済時の請求額ではないことを常時表示する。並び順の初期値は実質価格の昇順とするが、支払額順にも切り替えられる。

## 4. 実質価格の計算

### 4.1 用語と式

```text
税込商品価格 = 税込表示価格
              または 税別表示価格 + 消費税（1円未満はサイト表示に従って丸める）

適用値引き = 自動適用セール値引き + 適用確定クーポン値引き
支払額     = max(0, 税込商品価格 - 適用値引き) + 確定送料
実質価格   = 支払額 - 算入可能ポイント
```

- セール後の価格を取得した場合は、それを税込商品価格として扱い、同じセール値引きを再度引かない。
- クーポンとセールの併用可否、値引き順序、端数処理は各サイトの決済ルールを優先する。確認できなければクーポンを計算に含めない。
- 送料に対するポイント付与やクーポン適用は、明示的に確認できた場合だけ反映する。
- 実質価格は 0 円を下限とする。ポイントが支払額を超える表示はデータ異常として算入せず「要確認」とする。

### 4.2 ポイントを現金相当として扱う条件

次の条件を**すべて**満たすポイントだけを、1ポイント = 1円として実質価格に算入する。

1. 当該購入で付与されるポイント数を、ユーザー条件と付与上限を含めて確定できる。
2. 1ポイント = 1円で対象モール内の通常購入に利用できる。
3. 最低利用単位が1ポイントで、利用時に追加手数料がない。
4. 期間限定の場合は有効期限と用途が取得でき、画面に明記されている。
5. 会員ランク、決済手段、エントリー、アプリ利用、初回購入等の条件について、ユーザーが充足済みと明示したか、無条件付与である。

以下は算入せず「算入外ポイント」として別表示する。

- 条件充足を確認できないキャンペーンポイント
- 抽選、後日判定、購入後の別操作、レビュー投稿等を必要とするポイント
- 付与上限や付与率、円換算価値、有効期限、用途のいずれかが不明なポイント
- マイル、商品券、暗号資産など1ポイント = 1円で通常購入に直接使えない特典

ユーザー条件が未入力の場合は、誰でも無条件で得られる通常ポイントだけを算入する。ログイン状態や保有カード等を推測してはならない。

## 5. 未取得・未確認情報の扱い

不明値を `0円`、`無料`、または条件充足済みとして補完しない。

| 状況 | 画面表示 | 計算・比較 |
| --- | --- | --- |
| 送料が未取得、または地域未指定 | `送料 未確認` | 支払額・実質価格を `算出不可` とし、ランキング対象外 |
| 税込/税別区分または税率が不明 | `税区分 未確認` | 算出不可、ランキング対象外 |
| クーポン条件が未確認 | `クーポンあり（適用未確認）` | 値引きに含めず、適用時の参考額を併記してよい |
| ポイント条件が未確認 | `獲得予定 ○pt（算入外・条件未確認）` | 実質価格から引かない |
| ポイント数自体が未取得 | `ポイント 未確認` | 算入額を0円とし、実質価格に `ポイント未反映` を付記 |
| 取得日時が基準より古い | `情報が古い可能性` | 値は表示するが再取得を促す |
| 商品 URL または価格が未取得 | `情報を取得できませんでした` | 比較カードをエラー表示し、ランキング対象外 |
| 商品同一性が要確認 | `同一商品か要確認` と不足項目 | 確定商品のランキング対象外 |

未確認項目はカード上部の警告と詳細内訳の両方に表示する。算出不可の商品が安価に見えるような仮合計は表示しない。

## 6. 画面仕様

### 6.1 検索条件

- 商品キーワードまたは商品 URL
- 配送先都道府県（送料・税計算に必要）
- ユーザー条件（任意）: モール会員、会員ランク、指定決済手段、キャンペーンへのエントリー状況

任意条件が空欄の場合は「未確認」として扱い、該当するクーポン・ポイントを計算に含めない。

### 6.2 比較一覧

各カードに、商品同一性、支払額、実質価格、価格内訳、算入ポイント、算入外ポイント、未確認項目、取得日時、商品ページへのリンクを表示する。「計算根拠」を展開すると、式へ代入した全数値とポイント条件を確認できる。

警告ラベルは少なくとも次を用意する。

- `同一商品か要確認`
- `送料未確認・算出不可`
- `クーポン未反映`
- `ポイント未反映`
- `条件付きポイントを除外`
- `情報が古い可能性`

## 7. 代表商品による期待結果

以下は仕様確認用の固定例であり、実在サイトの現在価格を示すものではない。すべて取得時刻は `2026-09-13T12:00:00+09:00`、配送先は東京都とする。

### 例1: 家電（型番・色違いの除外）

検索対象: ワイヤレスイヤホン `ABC-100-BK`、JAN `4900000000016`、ブラック。

| 候補 | 内訳 | 同一性 | 期待結果 |
| --- | --- | --- | --- |
| A | 税込10,000円、送料無料、無条件100pt | 自動一致 | 支払額10,000円、実質価格9,900円 |
| B | 税込9,700円、送料500円、条件未確認の500pt | 条件付き一致 | 支払額10,200円、実質価格10,200円（500ptは算入外） |
| C | 型番`ABC-100-WH`、ホワイト、税込9,000円 | 不一致 | 色・型番違いとして比較対象外 |

**期待する順位:** A、B。表示価格だけならBが安いが、送料と算入可能ポイントを反映するとAが最安となる。

### 例2: 日用品（販売単位の区別）

検索対象: 洗剤 500 ml × 2本、JAN `4900000000023`。

| 候補 | 内訳 | 同一性 | 期待結果 |
| --- | --- | --- | --- |
| A | 税込1,200円、送料300円、200円クーポン自動適用、10pt | 自動一致 | 支払額1,300円、実質価格1,290円 |
| B | 税込1,350円、送料無料、無条件20pt | 自動一致 | 支払額1,350円、実質価格1,330円 |
| C | 1,000 ml × 1本、税込1,100円、送料無料 | 不一致 | 総量は同じでも個数違いとして比較対象外 |

**期待する順位:** A、B。Aは `1,200 - 200 + 300 = 1,300円` を支払い、10ptのみを差し引く。

### 例3: 書籍（送料不明と期間限定ポイント）

検索対象: 書籍、ISBN/JAN `9784000000000`。

| 候補 | 内訳 | 同一性 | 期待結果 |
| --- | --- | --- | --- |
| A | 税込2,200円、送料無料、通常22pt、期間限定100pt（期限・用途を確認済み） | 自動一致 | 支払額2,200円、実質価格2,078円 |
| B | 税込2,100円、送料未確認、通常21pt | 自動一致 | 支払額・実質価格とも算出不可、ランキング対象外 |
| C | 税込2,180円、送料無料、要エントリー200pt（未確認） | 自動一致 | 支払額2,180円、実質価格2,180円（200ptは算入外） |

**期待する順位:** A、Cの順。Bは本体価格が最安でも送料が不明なため順位に含めない。Aの期間限定ポイントは期限と用途が確認済みなので算入し、Cの要エントリーポイントは条件未確認として除外する。

## 8. MVP の完了判定

- 3サイトの取得結果を共通の表示項目へ変換できる。
- 同一性の根拠と不足項目をユーザーが確認できる。
- 支払額と実質価格を本仕様の式で再現でき、計算内訳を表示できる。
- ポイントの算入条件、算入外理由、未確認項目が比較画面に表示される。
- 算出不可・要確認の候補が最安ランキングへ混入しない。
- 本仕様の3例を自動テストまたは受け入れテストで再現できる。
